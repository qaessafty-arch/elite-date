# Java Hello World Project

## How to compile and run:

1. Open terminal in `java-project` directory:
   ```
   cd java-project
   ```

2. Compile:
   ```
   javac HelloWorld.java
   ```

3. Run:
   ```
   java HelloWorld
   ```

Expected output:
```
Hello, World! This is your first Java program.
```

## Next steps:
- Edit `HelloWorld.java` to add your code.
- Ensure JDK is installed (check with `java -version` and `javac -version`).
- For VSCode: Install "Extension Pack for Java".

You can now write and run Java programs here!
public class main(String[] args) {
    System.out.println("Hello, World! This is your first Java program.");
